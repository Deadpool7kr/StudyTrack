## Code Implementation pages

For each week’s “04. Code Implementation” page, capture the most relevant source code:
- Week 1: React entry point and App component
- Week 2: reusable component + props
- Week 3: `useState` task form/list
- Week 4: `useEffect` data loading/lifecycle code
- Week 5: React Router routes/navigation
- Week 6: `useMemo`, `useCallback`, `useRef` or custom hook
- Week 7: Node server and API fetch code
- Week 8: Express route definitions
- Week 9: Mongoose schema/model and MongoDB connection
- Week 10: REST CRUD route/controller code
- Week 11: frontend-backend integration and deployment configuration
